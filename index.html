    About Student Management System

    College PBL Micro Project — Web Application Development

    Project Overview

    This Student Management System is a web-based application developed as a college PBL micro project. It provides a simple interface for managing student records including student ID, name, email, phone, course/branch and semester.

    • Add, view, edit and delete students
    • Instant search, filters and sorting
    • Live dashboard statistics
    • Data saved in the browser (LocalStorage)
    • Fully responsive — works on mobile phones

    Technology Used

    • HTML5Semantic structure
    • CSS3Responsive styling
    • JavaScriptApplication logic
    • LocalStoragePersistent data
